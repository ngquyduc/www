Phase 1 design · quyduc.vercel.app · Astro + Tailwind v4

Ledger and instrument

A quiet editorial page (one sans, one mono, hairlines, lots of space) with one dark instrument on it: a live, simulated messaging demo: a phone-style DM screen (“what users see”) beside a dark engineer panel (“what I see”) that reacts to the same taps. The panel stays dark in both themes; the phone skin follows the theme. In light mode it is the only dark object on the page, so the eye lands there first. Everything else gets out of the way of the content.

02

Type

IBM Plex Sans 400/500/600/700 + IBM Plex Mono 400/500/600 · OFL · self-hosted WOFF2, Latin subset
{{t.name}} {{t.spec}} {{t.sample}}

Why Plex. It was drawn for engineering contexts: a sans with some character and a mono whose figures line up. Numbers matter on this site (prices, latencies, dates), so the mono carries all of them with font-feature-settings: "tnum", "zero".

Rules. Headings are 600–700 with negative tracking. Kickers and labels are mono, uppercase, +0.08em. Body is 17 px / 1.6 with a 40 rem reading measure (about 68 characters). Never more than 2 weights in one block.

Fallbacks. ui-sans-serif, system-ui, -apple-system, "Segoe UI", Roboto, sans-serif and ui-monospace, "SF Mono", Menlo, Consolas, monospace, with size-adjust fallback faces to keep CLS near 0.

Mobile. Under 760 px container width: display 38, 3xl 30, 2xl 24. Everything else is unchanged.

  • sm: tags, inline code, focus ring corners. md: buttons, inputs, figures. lg: the order book, palette, code blocks.
  • Borders are 1 px. line for hairlines between rows; line-strong for buttons and inputs; dashed 1 px accent for placeholders only.
  • No drop shadows on the page. One shadow exists: the palette dialog, 0 24px 64px rgb(0 0 0 / .28).
  • Focus ring: 2 px focus, 2 px offset. Inside the instrument: 2 px amber.

The hero demo plays one message on load (under 5 s), then moves only when the visitor acts. No scroll reveals, parallax or page transitions. Under prefers-reduced-motion: reduce every transition drops to 0 ms, the hero demo has no autoplay and completes instantly, and the order-book demo starts paused.
