Plate draw

On card hover or focus, the plate's accent path draws in (900 ms, pathLength=1 dash offset) and its accent label rises 4 px. CSS only.

Section rule

Each section head's ink rule grows from the left (scaleX 0 → 1, 600 ms) the first time it enters the viewport. One shared IntersectionObserver, under 0.4 KB.

Rolling figures

The ledger strip and card metrics roll their digits once on first view (the §7.5 roller, 320 ms, staggered 60 ms). The real value is in the HTML from the start.
