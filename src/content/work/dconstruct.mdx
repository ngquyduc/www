## Context

dConstruct builds a surveillance system that works on point clouds. Operators connect sensors, watch a live 3D view and play back recorded footage. It is a small startup, so I worked across the whole stack rather than inside one team.

Before the rebuild, training a new operator on the system took two days.

## What I built

**Endpoints in C++17 and SQLite 3, compiled with Emscripten,** for sensor connections, live view and video playback. Together they cut latency for real-time surveillance by 20%.

**The operator UI in SolidJS and TailwindCSS**, responsive across the screens operators actually use. Training a new operator now takes one day instead of two.

**A C++ PDF report generator** packaged as a library, so reports come out the same way every time. One project uses it so far.
